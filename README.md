## ✨ О проекте

**Console Delivery Service** — консольная административная панель для управления небольшой службой доставки. Приложение позволяет вести базу клиентов и курьеров, оформлять заказы, назначать исполнителей и отслеживать жизненный цикл каждого заказа.

Вместо хранения данных только в оперативной памяти проект использует **SQLite**: созданные записи сохраняются в локальном файле базы данных и остаются доступными после перезапуска приложения.

Проект разделяет основные обязанности между моделями предметной области, репозиториями для доступа к данным и консольным интерфейсом. Такой подход помогает не смешивать бизнес-правила, SQL-запросы и взаимодействие с пользователем в одном большом классе.

## 🚀 Возможности

### 📊 Главная панель
- Сводное количество заказов, клиентов и курьеров.
- Статистика заказов по статусам.
- Количество свободных курьеров.

### 📦 Управление заказами
- Создание заказа для существующего клиента.
- Добавление нескольких товарных позиций с количеством и ценой.
- Автоматический расчёт итоговой стоимости.
- Выбор способа доставки.
- Назначение свободного курьера, если он требуется.
- Поиск заказа по номеру и просмотр его состава.
- Изменение статуса с проверкой допустимых переходов.
- Удаление заказа.

### 👤 Управление клиентами
- Добавление клиента с проверкой основных данных.
- Просмотр списка клиентов и поиск по ID.
- Хранение имени, фамилии, возраста, телефона, электронной почты и адреса.
- Удаление клиента с учётом связей в базе данных.

### 🛵 Управление курьерами
- Добавление курьера и выбор транспорта.
- Просмотр списка курьеров и поиск по ID.
- Отметка курьера как свободного или занятого.
- Автоматическое занятие курьера при назначении на заказ и освобождение при завершении заказа.
- Защита от удаления занятого курьера.

| Быстрая доставка | 467 | 3 дня | Да |

## 🔄 Жизненный цикл заказа

```text
CREATED ──────► ASSIGNED ──────► IN_DELIVERY ──────► DELIVERED
   │                │                  │
   └──────► CANCELLED ◄───────────────┘
                    ▲
                    └── заказ можно отменить до завершения
```

- `CREATED` — заказ создан; состав и способ доставки можно менять.
- `ASSIGNED` — заказу назначен курьер.
- `IN_DELIVERY` — заказ передан в доставку или ожидает получения при самовывозе.
- `DELIVERED` — заказ доставлен.
- `CANCELLED` — заказ отменён.

Переходы между статусами контролируются перечислением `OrderStatus`. Завершённые заказы нельзя перевести в другой статус. Для самовывоза предусмотрен переход к `IN_DELIVERY` без назначения курьера.

## 🗄️ Хранение данных

Приложение использует локальную базу **SQLite**. По умолчанию применяется JDBC URL:

```text
jdbc:sqlite:delivery.db
```

При первом запуске `DatabaseManager` создаёт таблицы, если они ещё не существуют:

- `clients` — клиенты;
- `couriers` — курьеры;
- `orders` — заказы;
- `order_items` — товарные позиции.

Связи между заказами, клиентами, курьерами и товарными позициями поддерживаются внешними ключами. Проверка внешних ключей включается для каждого соединения.

Файл `delivery.db` создаётся относительно **рабочей директории запуска**. Если запускаете приложение из другой директории, файл базы может появиться именно там.

## 🛠️ Технологии

- **Java** — модели, бизнес-правила и консольное приложение.
- **JDBC** — взаимодействие Java с базой данных.
- **SQLite** — локальное реляционное хранение без отдельного сервера.
- **SQLite JDBC Driver** — библиотека `lib/sqlite-jdbc.jar`.

Для исходного кода требуется **JDK 17 или новее**. В проекте уже находится JAR-драйвер SQLite, поэтому отдельно скачивать его для запуска не требуется.

## ▶️ Запуск

### Вариант 1. IntelliJ IDEA

1. Откройте папку проекта в IntelliJ IDEA.
2. Убедитесь, что выбран JDK 17 или новее.
3. Подключите `lib/sqlite-jdbc.jar` как зависимость проекта:
   `File → Project Structure → Modules → Dependencies → + → JARs or Directories`.
4. Выберите `src/Main.java` и запустите метод `main()`.

Если IDEA не видит драйвер, проверьте, что JAR добавлен именно в зависимости запускаемого модуля, а не просто лежит в папке `lib`.

### Вариант 2. Терминал Windows (PowerShell)

Выполните команды из корневой папки проекта:

```powershell
# Компиляция исходников
javac -encoding UTF-8 -cp "lib/sqlite-jdbc.jar" -d out (Get-ChildItem -Recurse src -Filter *.java | ForEach-Object { $_.FullName })

# Запуск
java -cp "out;lib/sqlite-jdbc.jar" Main
```

### Вариант 3. Linux / macOS

Из корневой папки проекта:

```bash
mkdir -p out
javac -encoding UTF-8 -cp "lib/sqlite-jdbc.jar" -d out $(find src -name '*.java')
java -cp "out:lib/sqlite-jdbc.jar" Main
```

> Если появляется предупреждение `A restricted method in java.lang.System has been called` от `SQLiteJDBCLoader`, это предупреждение о доступе к нативному коду в новых версиях Java, а не обязательно ошибка работы приложения. Для его подавления можно добавить VM option `--enable-native-access=ALL-UNNAMED`.

## 🖥️ Как пользоваться

После запуска откроется главное меню:

```text
==================================
       DELIVERY ADMIN PANEL
==================================
1. Главная панель / статистика
2. Управление заказами
3. Управление клиентами
4. Управление курьерами
0. Выход
```

**Рекомендуемый сценарий демонстрации:**

1. Откройте раздел клиентов и добавьте клиента.
2. Добавьте курьера и выберите для него транспорт.
3. Перейдите к заказам и создайте заказ для этого клиента.
4. Добавьте одну или несколько товарных позиций и выберите доставку.
5. При необходимости назначьте свободного курьера.
6. Покажите заказ, его состав, стоимость и текущий статус.
7. Измените статус заказа и откройте главную панель, чтобы продемонстрировать обновление статистики.
8. Перезапустите приложение и покажите, что данные сохранились в SQLite.

## 🛡️ Проверки и ограничения

- Возраст, имя, фамилия, телефон и электронная почта проверяются при создании соответствующих объектов.
- Количество товара должно быть положительным, цена — неотрицательной.
- Нельзя менять состав заказа после выхода из статуса `CREATED`.
- Нельзя назначить курьера на самовывоз; для курьерской доставки проверяется доступность исполнителя.
- Удаление записей, на которые ссылаются другие записи, может быть запрещено ограничениями внешних ключей.
- Ввод пользователя обрабатывается консольным интерфейсом, а ошибки бизнес-правил и базы данных выводятся понятными сообщениями.

## 📌 Важно

Это **учебный проект**, а не готовая коммерческая платформа. Цены и сроки доставки заданы в коде для демонстрации принципов ООП и работы с данными. В текущей версии нет графического интерфейса, сетевого API, авторизации и реальной интеграции со службой доставки.
